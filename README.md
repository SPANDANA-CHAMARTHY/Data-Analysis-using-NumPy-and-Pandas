# Data-Analysis-using-NumPy-and-Pandas
# Python Data Analysis 

## 📌 Project Overview
This project focuses on practicing fundamental data analysis operations using **NumPy and Pandas in Python**. It covers NumPy array operations, Pandas Series, and DataFrame creation, exploration, filtering, and manipulation.

## 🎯 Objectives
- Understand NumPy arrays and their properties.
- Perform mathematical calculations and array slicing using NumPy.
- Create and manipulate Pandas Series.
- Create and explore Pandas DataFrames.
- Filter data based on specific conditions.
- Perform grouping and aggregation operations.
- Modify, add, and delete DataFrame rows and columns.

## 🛠️ Tools and Technologies
- **Programming Language:** Python
- **Libraries:** NumPy, Pandas
- **Environment:** Jupyter Notebook / Google Colab

## 📚 Topics Covered

### 1. NumPy Array Operations
- Creating one-dimensional and two-dimensional arrays.
- Checking array shape, data type, and size.
- Converting temperatures from Celsius to Fahrenheit.
- Calculating maximum, minimum, and mean temperatures.
- Practicing array slicing and indexing.

### 2. Pandas Series
- Creating a Series with custom index labels.
- Accessing elements using `loc` and `iloc`.
- Filtering values using Boolean conditions.
- Updating and removing Series elements.
- Calculating CGPA values by dividing marks by 10.

### 3. Pandas DataFrame
- Creating a transaction DataFrame.
- Exploring data using `head()`, `tail()`, `shape`, `columns`, `dtypes`, and `info()`.
- Selecting specific columns using column names.
- Retrieving columns using `iloc` and `loc`.
- Filtering transactions based on region and amount.
- Counting product categories using `value_counts()`.
- Finding unique region values using `unique()`.
- Calculating average transaction amounts using `groupby()` and `mean()`.

### 4. DataFrame Manipulation
- Updating the transaction amount for a specific TransactionID.
- Creating a Discount column calculated as 10% of the transaction amount.
- Removing a specific transaction row.
- Deleting the Discount column.

## 💡 Key Learnings
Through this assignment, I practiced:
- Working with numerical arrays using NumPy.
- Accessing and transforming data using Pandas.
- Applying indexing, slicing, and Boolean filtering.
- Performing basic data exploration and aggregation.
- Modifying DataFrames to meet specific requirements.

## 🚀 Conclusion
This assignment helped me strengthen my foundational Python data analysis skills using NumPy and Pandas. These concepts are important for data cleaning, data exploration, and further analysis in real-world data analytics projects.
